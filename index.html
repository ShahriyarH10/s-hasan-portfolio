Case studyMessManager

How the money adds up.

Shared houses ("messes") in Dhaka split meals, bazar, rent and utilities every month. MessManager turns that into one settlement everyone can check.

4active users
~32 KBJavaScript to load the landing page
8build steps: a static, vanilla JS app
2backends, one codebase: real + sandbox

  1. The engine

    Meal rate = total bazar ÷ total meals. Prepaid and postpaid utilities, credits and unpaid dues roll into the next month.

  2. One source of truth

    Every screen calls the same pure settlement functions, so numbers never disagree between pages.

  3. Payments

    Cash is allocated automatically: previous due → rent → utility → meal.

  4. Security

    Postgres row-level security scopes every query to one mess. Strict CSP: no inline scripts, no eval.

  5. Real time

    A database trigger calls an Edge Function that pushes notifications to the mobile app.

  6. A safe demo

    The same app code runs on an in-memory sandbox, so the public demo never touches real data.
